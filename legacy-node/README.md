# The TypeScript prototype

The first version of Ask the Dashboard: a Node API on PGlite or Postgres, a TypeScript MCP server, and a Vite-built panel and dashboard. The Spring Boot backend (`../backend`) and the Angular frontend (`../frontend`) replace it, with the same seed, the same API contract and the same MCP tools.

It's kept for reference only. Delete this folder when you no longer need it. Its scripts in `package.json` expect to run from the repo root, where they originally lived.
